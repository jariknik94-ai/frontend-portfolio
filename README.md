# Frontend Portfolio

Современный адаптивный сайт-портфолио frontend-разработчика, созданный с использованием React, TypeScript, SCSS и Vite.

---

## О проекте

Данный проект представляет собой персональный сайт-портфолио для демонстрации профессиональных навыков, технологий и выполненных проектов.

Проект разработан в рамках дипломной работы по направлению Frontend-разработка.

---

## Основные возможности

- Адаптивный интерфейс
- Современный premium UI
- Glassmorphism дизайн
- Светлая и темная темы
- Плавные анимации
- Анимации при прокрутке
- Модальные окна проектов
- Фильтрация проектов
- Интерактивная навигация
- Scroll Progress Bar
- Cursor Glow эффект
- Responsive layout
- Интеграция GitHub проектов

---

## Используемые технологии

### Frontend
- React
- TypeScript
- SCSS
- Vite

### UI / UX
- CSS Grid
- Flexbox
- Glassmorphism
- Responsive Design
- CSS Variables
- Animations

### Дополнительно
- React Icons
- LocalStorage
